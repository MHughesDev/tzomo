# Funding Applications (SOW §15.1 — grants-first, layered)

**Primary — apply during Phase 0** (cycles run months; apply while runway is long):
- **NLnet Foundation** (NGI programmes) — strong fit: open internet infrastructure, permissive
  license, European process friendly to solo maintainers. Prepare: project summary from SOW §1,
  budget, milestones mapped to Phase 0–1 deliverables.
- **Sovereign Tech Fund** — fit: foundational open digital infrastructure; strongest once a
  repo exists with visible activity (apply late Phase 0 / Phase 1).
- **CZI Essential Open Source Software for Science** — fit: the eigensolver/Laplacian line and
  scientific-computing users (scipy-adjacent story). Frame around `eigen`/`laplace`.
- **NSF POSE** — check eligibility (individual vs. institutional); pairs with the academic-
  affiliation option (§15.5) if pursued.

**Secondary:** GitHub Sponsors — enable at Phase 1 launch, passive.
**Tertiary:** consulting, time-boxed ≤1 day/week, from Phase 2 reputation onward.
**Fallback (documented):** paid role, project at ~⅓ velocity, phases stretch.

Verify each program's current cycle/eligibility at application time (assumption register:
programs HIGH CONFIDENCE, cycles CHECK).
